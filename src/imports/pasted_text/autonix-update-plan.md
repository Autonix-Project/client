신규 페이지 1 — 생산 주문 등록
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
사이드바에 "주문 등록" 메뉴 추가 (대시보드 아래)

페이지 구성:
· 상단 타이틀: "생산 주문 등록"
· 주문 입력 폼 카드:
  - 차종 선택 (드롭다운): 소나타 N라인 / 투싼 하이브리드 / 아이오닉6 / 팰리세이드 / 코나 일렉트릭
  - 생산 수량 (숫자 입력, 1~50)
  - 우선순위 선택 (라디오): 높음 / 보통 / 낮음
  - [생산 주문 등록] 버튼 (오렌지)
· 등록 시 성공 토스트 메시지: "주문이 등록되었습니다. 시뮬레이션을 시작합니다."
· 하단에 최근 등록 주문 목록 테이블
  컬럼: 주문번호 / 차종 / 수량 / 우선순위 / 등록시각 / 상태
  상태 배지: 대기중(회색) / 생산중(오렌지) / 완료(초록)

기존 페이지 수정 1 — 대시보드 차량 카드 클릭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
차량 상태 보드의 각 차량 카드(CAR-001 등) 클릭 시
→ 오른쪽에서 슬라이드인 되는 사이드 패널 표시

패널 구성:
· 헤더: 차량번호(크게) + 차종 + 현재상태 배지 + 예상완료시간
· 공정 타임라인 (세로):
  차체조립 → 도장 → 조립 → 품질검사 → 출고대기
  - 완료: 초록 원 + 완료시각 + 소요시간 ("1시간 23분")
  - 실패: 빨간 원 + "실패" 배지 + 실패사유 한 줄
  - 진행중: 오렌지 원 점멸(pulse) + 경과시간
  - 대기: 회색 원 + 예정시각 (흐리게)
· 이력 로그 (타임라인 아래):
  시간 역순 리스트
  형식: [시각] [내용] [심각도 배지(있을 때만)]
  실패 이력 행: 빨간 2px 좌측 보더
· 하단 KPI 4개 가로 나열:
  총 경과시간 / 재작업 횟수 / 담당 라인 / 잔여 공정 수
· 패널 외부 클릭 또는 X 버튼으로 닫기

mock 데이터: CAR-006 기준
  차체조립 완료(45분) → 도장 실패(기포 불량) → 도장 재작업 중

기존 페이지 수정 2 — 라인 관리 카드 클릭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
각 라인 카드(조립 라인 A 등) 클릭 시
→ 라인 상세 모달 표시

모달 구성:
· 헤더: 라인명 + 상태 배지
· 스테이션 맵 (가로):
  5개 스테이션을 원형 아이콘으로 표시
  완료(초록) / 진행중(오렌지 점멸) / 대기(회색)
  원 아래 스테이션명 (프레임 / 용접 / 차체 / 조립 / 검사)
  원들을 1px 선으로 연결
· 현재 할당 차량 목록:
  CAR번호 + 차종 + 현재 스테이션 + 경과시간
· 오늘 완료 차량 수 / 평균 사이클 타임 / 가동률 추이 (미니 바차트 7개)
· 닫기 버튼

기존 페이지 수정 3 — 재고 관리 부품 행 클릭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
재고 테이블의 각 부품 행 클릭 시
→ 부품 상세 모달 표시

모달 구성:
· 부품명 + 부품코드(INV-XXX) + 현재 상태 배지
· 재고 현황 바 (크게): 현재고 / 최소기준 수치 표시
· 최근 7일 입출고 내역 테이블
  컬럼: 날짜 / 구분(사용/입고) / 수량 / 잔여 / 관련차량
· 예상 소진일 ("현재 생산 속도 기준 약 3일 후 소진 예정")
· 닫기 버튼

기존 페이지 수정 4 — 배송 카드 클릭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
배송 목록의 각 SHIP 카드 클릭 시
→ 배송 상세 모달 표시

모달 구성:
· 헤더: 배송번호(SHIP-XXX) + 상태 배지
· 차량 정보: 차량ID / 차종 / 출발지(공장명) / 목적지
· 배송 진행 타임라인 (가로 3단계):
  출고대기 → 배송중 → 배송완료
  현재 단계 오렌지 강조, 완료 단계 초록
· 배송 진행률 바 (배송중일 때만)
· 출발시각 / 예상도착시각 / 배송 차량번호
· 닫기 버튼
